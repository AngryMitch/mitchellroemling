# About this project

You're looking at it. This site is a static **Astro** project styled to look like an old Windows desktop, deployed to **Cloudflare Pages**.

# Highlights

- Static-first, zero client JS on first paint
- Content managed as Markdown in Git
- Custom Win95/XP component library (windows, taskbar, start menu, BSOD 404)

# What I learned

- How Astro builds and ships code
- The limits of Cloudflare pages
- How to use CSS vars
- Introduced to Keystatic
